        #交互点方向 / 接口硬件表现
        
        
          
        1复习任务到点提醒 已有
            服务端每 30s 扫描 → POST {ESP32}/remind
            LED 亮 + 蜂鸣器响 1.5s
        
          
        2手动测试提醒 已有
            POST /api/hardware/test → /remind
            同上，用于答辩现场演示
        
          
        3番茄钟到点提醒 新增
            POST /api/focus/sessions → /remind
            专注完成时声光提醒休息
        
          
        4专注状态灯 新增
            POST /api/focus/state → POST {ESP32}/focus
            专注中 LED 常亮，结束熄灭
        
          
        5学习状态看板（上行轮询）新增
            ESP32 定时 GET /api/hardware/status
            OLED / 串口显示待复习数、待掌握错题数、专注状态
        
          
        6通用消息下发（预留）
            esp32.notify_esp32(task, message)
            可扩展每日打卡、考试倒计时提醒
