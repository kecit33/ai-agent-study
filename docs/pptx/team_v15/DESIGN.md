> 依据 `academic.md`（学术研究报告 / 课程作业答辩）+ `design-principle.md`。
> 需求对齐结果：主题=智能体开发课程作业 V1.5.0；目标=团队展示 + 选题报告 + 成果展示 + 需求分析，供最终验收参考；受众=课程验收教师 / 助教 / 答辩评审；调性=平实、证据驱动、不画大饼；页数=22 页；交付=单份 .pptx。
