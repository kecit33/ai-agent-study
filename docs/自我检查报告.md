### 8.2 安全性确认

Markdown 渲染器采用 **escape-first** 策略：先 `mdEscape` 把 `& < > " '` 全部转义，再做行内/块级标记替换。因此即便模型或用户输入含 `<script>`、`<img onerror=...>` 等，也会被转义为纯文本，不会执行。Node 单测用例 `**x** <img src=x onerror=alert(1)>` 输出为 `<p><strong>x</strong> &lt;img src=x onerror=alert(1)&gt;</p>`，确认 XSS 安全。
