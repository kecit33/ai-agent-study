```markdown
## 第三章 微分中值定理与导数的应用

**本章定位**：中值定理把「局部导数」与「整体增量」连接起来，是证明题的核心工具；泰勒公式与洛必达法则把极限计算推进到高阶；再用一、二阶导数系统刻画单调性、极值、凹凸性与曲率。

### 知识点清单
1. **三大中值定理** — 费马引理、罗尔定理、拉格朗日中值定理、柯西中值定理及辅助函数构造。
2. **泰勒公式** — 带皮亚诺/拉格朗日余项的泰勒展开；常用函数在 x=0 的麦克劳林公式。
3. **洛必达法则** — 0/0 与 ∞/∞ 型；其他未定式的转化；使用前提条件与失效情形。
4. **单调性、极值与最值** — 驻点与不可导点；一阶导符号判定；闭区间最值的比较法；实际优化问题。
5. **凹凸性、拐点与曲率** — 二阶导符号与拐点；弧微分与曲率 K = |y''|/(1+y'²)^(3/2)。

### 公式 / 定理速查
- `拉格朗日：f(b) − f(a) = f'(ξ)(b − a)，ξ ∈ (a, b)；柯西：f(b)−f(a) / g(b)−g(a) = f'(ξ)/g'(ξ)`
- `泰勒：f(x) = Σ(k=0..n) f^(k)(x₀)/k!·(x−x₀)^k + R_n(x)`
- `e^x = 1 + x + x²/2! + x³/3! + o(x³)；sin x = x − x³/3! + o(x³)`
- `ln(1+x) = x − x²/2 + x³/3 + o(x³)；(1+x)^α = 1 + αx + α(α−1)x²/2 + o(x²)`
- `洛必达：lim f/g = lim f'/g'（仅 0/0、∞/∞ 且右端极限存在或为 ∞）`

### 高频易错点
- 洛必达法则只适用于 0/0 与 ∞/∞，且要求导数之比的极限存在；滥用会得出伪结论。
- 中值定理前提条件（闭区间连续、开区间可导）必须逐条验证。
- f'(x₀)=0 只是极值的必要非充分条件，y = x³ 在 x=0 是驻点但不是极值点。
- f''(x₀)=0 不一定为拐点（如 y = x⁴），必须看两侧二阶导是否变号。

### 学法与考点
- 学法：证明题先识别要证的不等式/等式适合哪个定理，再构造辅助函数；应用题固定流程为「求 f' 找驻点 → 划分区间判单调 → 求 f'' 判凹凸与拐点 → 比较端点与极值定最值」。
- 常考：罗尔/拉格朗日定理证明题、洛必达与泰勒求极限、单调性与极值、最值应用题、凹凸性与拐点、渐近线与曲率。

```
