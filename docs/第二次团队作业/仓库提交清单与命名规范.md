## 5 导出与复现

```bash
cd ai-campus-companion/docs/第二次团队作业

python gen_diagrams.py     # 重新生成 assets/*.svg
python gen_modao_v150.py   # 重新生成 modao_v150/*.html、html_list.json、原型需求核对表.md
python gen_modao_shots.py  # 由原型 HTML 生成 assets/原型_*.png
python build_docs.py       # 由两份 .md 生成同名 .pdf（Chrome / Edge 无头打印）
```

正文改动只改 `.md`，再运行 `python build_docs.py` 重生成 PDF；图改动只改 `gen_diagrams.py` 后重跑；原型改动只改 `gen_modao_v150.py` 的 `PAGES` 数据，重跑后需把新的 `html_list.json` 重新导入墨刀，并同步 `gen_modao_shots.py`。不得直接编辑 PDF 或手工改 `modao_v150/*.html`，避免单一源漂移。补齐 R01 – R12 后须重跑一次并检查【重点】标记是否按检查结果更新。
