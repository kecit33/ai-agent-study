| 博客随笔 | `「团队名称」第二次团队作业——原型设计+概要设计`，无版本号、无空格 | `无言以对第二次团队作业——原型设计+概要设计.md` |

| 版本标识 | 写在文档正文「文档控制信息」表内，不写入文件名；本次统一标注「对应产品 V1.5.0 验收基线」 | — |
| 编码 | 全部正文与源文件 UTF-8；PDF 由 HTML 无头打印导出，中文字体 `Microsoft YaHei` | — |
| 禁止 | 不使用 `final` / `v2` / `副本` / `新建` / 日期后缀；不保留中间产物（如 `_pdftest.*`）作为提交件 | — |

## 5 导出与复现

```bash
cd ai-campus-companion/docs/第二次团队作业

python gen_diagrams.py     # 重新生成 assets/*.svg
python build_docs.py       # 由两份 .md 生成同名 .pdf（Chrome / Edge 无头打印）
```

正文改动只改 `.md`，再运行 `python build_docs.py` 重生成 PDF；图改动只改 `gen_diagrams.py` 后重跑。不得直接编辑 PDF 或手工改 HTML，避免单一源漂移。
