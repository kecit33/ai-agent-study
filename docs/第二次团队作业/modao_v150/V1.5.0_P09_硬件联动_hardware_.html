P09 硬件联动（hardware）

ESP32 接口清单与状态看板；仅表达连接设计，不代表物理验证已完成。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-inputhwTask 输入框placeholder：复习任务名，如：复习第3章
v15-action-btn创建任务 / 测试提醒 / 专注灯POST /api/hardware/test、GET /api/hardware/status
v15-hw-table6 点硬件交互清单表下行提醒 / 专注灯 + 上行状态看板共 6 个交互点
v15-status-board状态看板展示版本指纹、Provider 状态、待复习 / 待掌握 / 专注状态

交互状态

默认态：清单表与看板可见未配置态：未配置 ESP32_ENDPOINT 返回 sent: false 与原因边界声明态：ESP32 未实机联调，物理声光效果未验证

业务流程

创建任务 / 测试提醒 → 后端尝试下发 → 未配置端点时返回 sent: false 与原因 → 主体功能不受影响。

规则与边界

本页为可选加分项，明确不列入验收；不得把连接图或界面截图当作实物照片。
