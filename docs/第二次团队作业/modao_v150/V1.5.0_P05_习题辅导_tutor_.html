P05 习题辅导（tutor）

引导式辅导：给分步思路与提示，不直接给最终答案。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-big-textareatutorText 文本域placeholder：在此粘贴题目…
v15-mic-btn语音输入Web Speech API（F25 / A28）
v15-action-btn「辅导一下」按钮POST /api/tutor，请求中禁用
v15-result结果区分步思路 + 提示，按安全 Markdown 排版

交互状态

默认态：题目输入区可用忙碌态：按钮禁用结果态：展示分步思路与提示异常降级态：逐模块错误提示

业务流程

粘贴题目 → 点击辅导一下 → 返回分步思路与提示 → 安全 Markdown 渲染。

规则与边界

与课件总结页共享输入组件 v15-big-textarea 与状态规则，保持组件命名与表现一致。
