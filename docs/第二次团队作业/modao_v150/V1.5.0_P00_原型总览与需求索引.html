后台管理原型边界（不额外假设）

作业原文要求「前台应用与后台管理原型」，未要求「独立后台站点」。M01 – M05 只重组 V1.5.0 真实存在的管理操作与真实 REST 路由（课程与资料、运行配置、状态看板、任务与专注、错题归档），与前台同源、共用同一在线预览链接；不虚构登录、权限、用户管理、多租户或统计大盘。系统按单机单用户设计，暂无登录与权限。

版本边界（不画大饼）

无真实厂商 API Key，演示模式是规则化应答而非大模型推理；课程记忆为全文拼接，不是检索增强；ESP32 未实机联调（F37 不列入验收）；长文档记忆与多用户属愿景中的未来期望，不是 V1.5.0 已实现能力。

排除的旧版口径

不引入其他版本的页面、字段、接口与交互；本原型不出现双后端、旧厂商数量、旧功能编号段或旧库表数量等表述。
