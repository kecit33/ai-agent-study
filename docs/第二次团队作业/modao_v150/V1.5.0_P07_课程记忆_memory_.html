P07 课程记忆（memory）

课程资料全文沉淀处，也是杀手级功能 F06 / F33 的数据入口。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-inputmatTitle 输入框placeholder：资料标题（可选）
v15-big-textareamatContent 文本域placeholder：粘贴本课程课件、笔记、重点…
v15-upload文件上传区白名单 .txt / .md / .markdown / .docx，≤ 2 MB、≤ 2 万字
v15-material-list已上传资料列表每条含「查看全文 / 收起」与「下载 .md」（F07 / A11）
v15-course-bar课程选择条新建 / 切换课程，课程名唯一非空（F05 / A10）

交互状态

默认态：显示真实资料，如「第 3 章 树与二叉树」空态：无资料时列表提示上传中态：按钮禁用与进度提示展开态：全文安全渲染 / 收起校验失败态：课程不存在返回 400；类型或大小不合规逐项提示（F32 / A35）

业务流程

选课程 → 粘贴或上传资料 → 保存进该课程 → 资料全文拼入问答上下文 → 切换课程即切换记忆。

规则与边界

单份 4000 字、总量 12000 字预算（F33 / A36）；docx 全实体还原、SQLite 并发等待（F36 / A39）。
