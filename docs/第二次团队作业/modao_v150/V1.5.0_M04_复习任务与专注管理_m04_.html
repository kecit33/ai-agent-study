⑤ 业务流程与规则边界

添加任务或生成计划 → 写入 review_tasks / 展示逐日安排 → 后台每 30 秒扫描到期任务 → 标记完成 → 专注记录回写概览统计。

任务 course_id 可空；计划文本按安全 Markdown 渲染；统计与列表统一转义（F31 / A34）。
