P06 复习计划（plan）

按科目与天数生成逐日复习安排。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-inputplanSubject 输入框placeholder：考试科目，如：数据结构
v15-input天数输入生成「第 1 天」至「第 N 天」逐日安排
v15-action-btn生成计划按钮POST /api/review-plan
v15-result结果区安全 Markdown 排版逐日计划

交互状态

默认态：科目与天数待填忙碌态：按钮禁用结果态：逐日安排可 30 秒扫描完异常降级态：失败提示不影响其他模块

业务流程

填科目与天数 → 生成计划 → 逐日安排渲染 → 可结合复习任务到点提醒（F12 / A15）。

规则与边界

后台线程每 30 秒扫描到期任务；计划文本按安全 Markdown 渲染（F27 / A30）。
