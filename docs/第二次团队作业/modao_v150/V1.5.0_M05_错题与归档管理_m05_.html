⑤ 业务流程与规则边界

录入错题 → 错因分析 + 同类变式题 → 标记掌握 → 按状态筛选 → 导出 Markdown 归档。

导出走 fetch + blob，失败只提示、不替换页面（F36 / A39）；无 DELETE 路由，不提供在线删除；导出内容不含密钥明文。
