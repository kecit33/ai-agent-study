P08 错题本（wrong）

录入 → 错因分析 + 变式题 → 标记掌握 → 筛选 → 导出，形成复习闭环。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-inputwqQuestion 文本域placeholder：错题题目
v15-inputwqUser 输入框placeholder：我的答案（可选）
v15-inputwqCorrect 输入框placeholder：正确答案（可选）
v15-filter掌握状态筛选下拉GET /api/wrong-questions，按状态筛选（F09 / A13）
v15-action-btn错因分析 / 变式题 / 标记掌握 / 导出POST .../analyze、POST .../master、GET .../export
v15-wrong-list错题列表全部字段统一转义（F31 / A34）

交互状态

默认态：错题列表有值空态：筛选无结果显示空列表忙碌态：分析与导出按钮禁用校验失败态：课程不存在拒绝写入（F32 / A35）

业务流程

录入题干 / 我的答案 / 正确答案 → 错因分析 + 生成同类变式题 → 标记掌握 → 按状态筛选 → 导出 Markdown。

规则与边界

导出走 blob 下载，失败不替换页面；docx 解析健壮性见 F36 / A39。
