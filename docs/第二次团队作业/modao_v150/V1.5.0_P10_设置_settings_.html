P10 设置（settings）

主题三档 + 六类 Provider 运行时配置，无密钥自动回退演示模式。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-theme主题三档与 6 套色板跟随系统 / 手动三档、自定义主色、本地持久化（F24 / A27）
v15-inputagentKey 密码框placeholder：必填，如 sk-… / 千帆 API Key
v15-inputagentSecret 密码框placeholder：仅文心旧版 WenxinWorkshop 需要
v15-inputagentModel 输入框placeholder：留空用默认：ernie-3.5-8k / moonshot-v1-8k
v15-inputagentBaseUrl 输入框placeholder：可选；千帆 v2 或自定义端点必填
v15-inputagentTokenUrl 输入框placeholder：仅文心旧版需要，可留空
v15-provider-card6 个 Provider 状态卡OpenAI / 文心一言 / Kimi / Claude / 自定义 / 演示模式（F20 / A23）
v15-action-btn保存 / 连通性自检 / 清除POST /api/agent/credentials、/test、/credentials/clear

交互状态

默认态：演示模式激活，表单可填配置生效态：运行时写入即时生效，无需重启（F21 / A24）自检态：真实探针校验并提示结果（F22 / A25）回退态：清除配置或调用异常后自动回退 demo（F23 / A26）掩码态：状态接口只返回密钥掩码，不回明文（F31 / A34）

业务流程

选择 Provider → 填密钥 / 模型 / 地址 → 保存或自检 → 激活项写入运行时 SQLite → 未配置或异常自动回退演示模式。

规则与边界

配置优先级：运行时 SQLite ＞ .env ＞ demo；本项目无真实厂商 API Key，演示模式是规则化应答而非大模型推理。
