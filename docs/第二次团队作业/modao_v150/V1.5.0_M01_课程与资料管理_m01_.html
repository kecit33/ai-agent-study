字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-course-bar课程选择 / 新建课程名唯一非空，空名返回 400（F05 / A10 / A04）
v15-input / v15-big-textareamatTitle / matContent资料标题可选；正文必填；全文安全渲染（F07 / A11）

交互状态

默认态：课程与资料列表有值空态：无资料时列表提示校验失败态：课程不存在 / 空课程名 / 类型或大小不合规逐项提示（F32 / A35）上传中态：按钮禁用与进度提示

业务流程

新建或选择课程 → 粘贴 / 上传资料 → 校验课程存在与文件白名单 → 落库到该课程 → 列表刷新 → 资料全文进入该课程问答上下文。

规则与边界

课程是记忆隔离单元；资料与错题写入前显式校验课程存在，拒绝孤儿数据。无 DELETE 路由，暂不提供在线删除；本页不新增未实现的权限或用户管理。
