P01 学习概览（dashboard）

一屏聚合课程复习状态；六项统计、待复习任务、番茄钟与最近专注记录。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-stat-card × 6统计卡片（可聚焦）Tab / Enter / Space 激活；无误题显示「暂无」而非 0.0%
v15-quick-taskquickTask 输入框placeholder：任务名，如：复习数据结构第 3 章
v15-quick-task添加 / 完成按钮POST /api/review-tasks、POST /api/review-tasks/{id}/done
v15-pomodoro番茄钟与专注状态GET /api/focus/state、GET/POST /api/focus/sessions
v15-course-bar顶栏课程选择条全局生效，切换课程刷新本页统计

交互状态

默认态：六项统计与待复习列表有值空态：无误题显示「暂无」键盘焦点态：统计卡片与上传区有 focus-visible 焦点样式异常降级态：单个接口失败逐模块提示，页面仍可操作（F30 / A33）

业务流程

进入页面 → 拉取 /api/overview 与复习任务 → 六项统计渲染 → 添加 / 完成任务 → 后台每 30 秒扫描到期任务并下发提醒。

规则与边界

空任务名回落默认名（F32 / A35）；统计与列表统一转义（F31 / A34）。
