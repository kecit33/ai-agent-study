交互状态

默认态：六项统计与待复习列表有值空态：无误题显示「暂无」键盘焦点态：统计卡片与上传区有 focus-visible 焦点样式异常降级态：单个接口失败逐模块提示，页面仍可操作（F30 / A33）

业务流程

进入页面 → 拉取 /api/overview 与复习任务 → 六项统计渲染 → 添加 / 完成任务 → 后台每 30 秒扫描到期任务并下发提醒。

规则与边界

空任务名回落默认名（F32 / A35）；统计与列表统一转义（F31 / A34）。
