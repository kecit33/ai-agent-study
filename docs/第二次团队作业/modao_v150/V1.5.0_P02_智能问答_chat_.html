P02 智能问答（chat）

课程内问答：切换课程即切换课程记忆，是本项目杀手级功能的界面入口。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-mode-banner演示模式提示条未配置密钥或调用异常时回退 demo，响应带 fallback 标记（F23 / A26）
v15-chat-log对话区回答按安全 Markdown 渲染，先转义再解析（F27 / A30）
v15-chat-inputchatInput 文本域placeholder：输入课程问题，或点右侧 🎤 语音输入（Chrome / Edge）…
v15-mic-btn语音输入按钮Web Speech API，覆盖 5 处输入（F25 / A28）
v15-send-btn发送按钮请求期间禁用并提示，结束恢复（F28 / A31）
v15-course-bar课程选择条切换时清空对话；过期异步响应丢弃（F34 / A37）

交互状态

默认态：对话区空、输入可用忙碌态：发送按钮禁用并显示状态回退态：演示模式提示条 + fallback 标记切课程态：对话清空、上下文重建

业务流程

选择课程 → build_course_context(course_id) 拼入该课程资料全文 → 交给 AgentProvider.complete() → 安全 Markdown 渲染回答。

规则与边界

单份资料 4000 字、总量 12000 字预算，超出按序保留并提示（F33 / A36）；课程记忆为全文拼接，不是检索增强。
