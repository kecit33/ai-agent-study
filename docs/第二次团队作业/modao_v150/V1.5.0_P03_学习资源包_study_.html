P03 学习资源包（study）

按教材 / 章节 / 题量 / 难度生成五件套，支持一键全套与导出。

字段 · 组件 · 文案与规则

组件（统一前缀 v15-）字段 / 控件文案或规则
v15-study-paramstudySubject 输入框默认值：高等数学上册；placeholder：如：数学 / 高等数学上册
v15-study-param章节 / 题量 / 难度学科目录与别名解析，未内置学科返回 discipline=自定义科目（F13 · F19）
v15-action-btn × 7自测题 / 总结 / 文章 / 资料 / 思维导图 / 一键全套 / 导出5 个生成按钮统一忙碌态
v15-result × 5题目 / 总结 / 专题文章 / 资料清单 / 思维导图题目含标准答案、分步解析与考点（F14）
v15-export导出 Markdownblob 下载失败不替换页面（F36 / A39）

交互状态

默认态：参数区可编辑、五区待生成忙碌态：5 个按钮同时禁用部分失败态：双请求独立判错，资料链接协议白名单（F35 / A38）直达态：/?autopack=1#study 打开即自动生成全套资源

业务流程

选学科与章节 → 单动作生成或一键五件套 → 五区分别渲染 → 可回写课程记忆 → 导出 Markdown。

规则与边界

思维导图输出树 JSON + SVG + Markdown 大纲 + Mermaid（F17 / A20）；一键全套走 POST /api/study/pack（F18 / A21）。
