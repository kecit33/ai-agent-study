交互状态

默认态：演示模式激活，表单可填配置生效态：写入即生效（F21 / A24）自检态：真实探针返回可用 / 不可用（F22 / A25）回退态：清除或异常后自动回退 demo（F23 / A26）掩码态：只回密钥掩码

业务流程

选 Provider → 填密钥 / 模型 / 地址 → 保存或自检 → 激活项写入运行时 SQLite → 未配置或异常自动回退演示模式。

规则与边界

配置优先级：运行时 SQLite ＞ .env ＞ demo；未知 Provider 或必填不全返回明确错误且不切换激活项。本项目无真实厂商密钥，演示模式为规则化应答。
