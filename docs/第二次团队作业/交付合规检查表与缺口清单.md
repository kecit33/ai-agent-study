## 5 【重点】缺口的统一处理规则

1. **编号唯一**：R01 – R12 为四份文档与图注共用的唯一缺口编号，不另起编号，避免同一缺口多处口径不一。
2. **双标注格式**：`【重点】` 表示合规判定（该项未满足），`【待填写：…】` 表示待补字段；二者并列出现时，前者是判定、后者是字段。仅当字段确实为空时才使用后者。
3. **禁止代填**：链接、访问密码、云盘提取码、照片、视频、拍摄日期、GitHub 账号、平台名称与地址、看板 / 燃尽图、任务卡编号、逐人 commit / PR / Issue 统计——以上任何一项均不得由助手推测、占位式伪造或以等价物冒充。
4. **等价物必须说明**：已上线系统可代替「可运行高保真原型」走查，但**不能**代替 Axure / 墨刀 原型源文件或在线预览；硬件连接图可满足作业原文「照片或连接图」的措辞，但**不能**充当实物照片。凡使用等价物，文档须同时写明差额。
5. **单一源**：博客、两份说明书 `.md`、提交清单与本表均为单一源文本；改动只改 `.md`，再运行 `python build_docs.py` 重导 PDF；图改动只改 `gen_diagrams.py` 后重跑。
