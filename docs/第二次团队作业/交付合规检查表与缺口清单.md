5. **单一源**：博客、两份说明书 `.md`、提交清单与本表均为单一源文本；改动只改 `.md`，再运行 `python build_docs.py` 重导 PDF；图改动只改 `gen_diagrams.py` 后重跑；原型改动只改 `gen_modao_v150.py` 的 `PAGES` / `MPAGES` 与 `gen_modao_interactive.py` 的 `ACTS`，依次重跑 `python gen_modao_v150.py`、`python gen_modao_ops.py`、`python gen_modao_navfix.py`、`python gen_modao_hotzones.py`、`python gen_modao_shots.py`；在线同步采用单页建工程 + 分批结构化写入 + 画布与热区补写，并用 `get_proto_details` 复核 16 页 / 16 画布 / 100 热区。
